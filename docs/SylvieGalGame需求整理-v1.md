# SylvieGalGame需求整理-v1


Galgame 播放器【一期核心功能清单】


前提：**无编辑器、纯 YAML 脚本驱动、React+Electron、仅播放器（玩家端）**
目标：跑通完整的线性 + 分支视觉小说游玩流程，可打包 exe，优先保证核心体验，砍掉所有非必要模块。

## 一、脚本引擎 & 指令调度（核心底座）

1. YAML 脚本加载解析：按场景文件加载，支持拆分多场景脚本，支持`import`引入其他场景 yaml
2. 指令调度器（指针 + 阻塞等待模型）
   - 区分【即时指令】、【阻塞等待点击指令】
   - 支持`label`标记、`jump`无条件跳转
   - 支持`choice`选择分支，选项可绑定跳转目标、条件显隐
   - 支持`set`变量赋值、数值增减
   - 支持`if`条件分支，基于变量判断走不同剧情
3. 内置变量系统
   - 变量类型：数字、布尔、字符串
   - 变量生命周期：跟随存档，全局跨场景生效
4. 文本已读标记系统：每条对话记录是否已读，用于 Skip 逻辑判断
5. 脚本基础校验：启动时检测指令基础结构，缺失资源输出控制台警告（一期只做控制台，不做 UI 报错面板）

> 
> 支持指令列表：`bg`、`sprite`、`cg`、`text`、`bgm`、`se`、`voice`、`label`、`jump`、`choice`、`set`、`if`、`wait`、`import`

## 二、图层渲染系统（React 分层渲染）

图层顺序（由底到顶）：背景层 → 立绘层（多立绘共存） → CG 全屏层 → 文本 UI 层 → 选项层 → 菜单遮罩层

1. 背景图层
   - 切换背景图，支持 fade 淡入淡出转场
2. 立绘图层
   - 多角色立绘同时显示，独立 id 管理
   - 切换立绘素材、调整横向位置、显隐控制
   - 透明度控制、fade 淡入淡出动画
3. CG 全屏图层
   - 全屏 CG 弹窗展示，淡入淡出
4. 统一动画：一期只做 fade，不做擦除、滑动、粒子等复杂转场

## 三、文本对话系统

1. 打字机逐字输出效果，可配置全局打字速度
2. 交互逻辑：
   - 打字播放中点击画面 / 空格：立刻渲染全部文字，不跳转下一句
   - 文字打完处于等待状态时点击画面 / 空格：进入下一条指令
3. 自动播放（Auto）
   - 开关控制，可配置等待时长；等待结束自动模拟点击推进剧情
4. 跳过模式（Skip）
   - Ctrl 快捷键开启 / 关闭
   - 规则：仅自动跳过【已读对话】，读到未读对话自动停止 Skip
5. 对话历史回看（Backlog）
   - 打开历史面板，查看过往对话、角色名
   - 历史条目可回放对应语音

## 四、音频系统

1. 三类音频独立管理：BGM 背景音乐、SE 音效、VO 角色语音
2. 能力：播放、停止、淡入淡出、循环（仅 BGM）
3. 独立音量控制：BGM / SE / VO 三个音量滑块
4. 语音绑定：text 指令绑定语音文件，文字开始打字时同步播放语音；新语音自动打断上一条语音
5. 资源预加载：进入场景提前预加载当前场景图片、音频，减少卡顿

## 五、存档、读档系统

1. 手动存档槽位：预留 20 个存档位
2. 自动存档：每次进入新分支 / 新对话自动覆盖 auto 存档
3. 存档内容：脚本指针位置、全部变量、图层状态、音频状态、已读标记
4. 存档截图快照：保存当前画面缩略图、存档时间、章节备注
5. 快捷操作：Ctrl+S 快速存档、Ctrl+L 快速读档
6. 存档管理：覆盖存档、删除存档

## 六、UI 面板 & 菜单系统

1. 标题首页：开始新游戏、继续游戏、读档、设置、退出
2. 游戏内菜单（Esc 唤起）
   - 继续游戏
   - 读档界面
   - 设置界面
   - 返回标题
   - 退出游戏
3. 设置面板
   - BGM/SE/ 语音音量调节
   - 打字速度调节
   - 窗口模式：窗口 / 全屏切换
   - 字体选择
4. 文本框 UI：角色名展示、对话文本区域，样式基础可配置

## 七、快捷键绑定

- 空格 / 回车：推进对话（对应 onUserInteract）
- Ctrl：Skip 跳过开关
- A：Auto 自动播放开关
- Esc：打开 / 关闭菜单
- Ctrl+S：快速存档
- Ctrl+L：快速读档

## 八、打包与资源加载（Electron 主进程能力）

1. 本地资源读取：读取 assets 下 yaml 脚本、图片、音频
2. 路径兼容：开发环境 & 打包 exe 后资源路径统一处理
3. 打包输出：electron-forge 打包 Windows 独立 exe 播放器
4. 资源策略：一期松散资源文件，不做高强度加密
