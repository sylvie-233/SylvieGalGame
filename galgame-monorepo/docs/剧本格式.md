# YAML 剧本格式

一期剧本完全由 YAML 驱动，没有编辑器。本文档对应 `packages/engine-core` 的实际解析行为，可直接作为写作与排错参考。

## 目录约定

内容包根目录（下称“游戏根”）默认是 `packages/game-content/game`：

```text
game/
├─ scripts/
│  ├─ game.yaml          # 清单（必填）
│  └─ scenes/
│     ├─ prologue.yaml
│     ├─ smile_route.yaml
│     └─ ...
├─ images/
│  ├─ bg/
│  ├─ sprite/
│  └─ cg/
└─ audio/
   ├─ bgm/
   ├─ se/
   └─ voice/
```

所有资源路径都相对于游戏根，例如 `images/bg/library_afternoon.svg`、`audio/voice/sylvie_01.wav`。引擎不会自动补全扩展名或目录。

## game.yaml

```yaml
title: 午后的回声
version: 0.1.0
start: prologue
scenes: [prologue, smile_route, book_route, common]
variables:
  affection: 0
  curiosity: 0
  knows_melody: false
  route: ""
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 否 | 标题页显示，默认 `Sylvie Galgame` |
| `version` | 否 | 标题页显示，默认 `0.1.0` |
| `start` | **是** | 新游戏入口场景 |
| `scenes` | 否 | 需要加载的场景列表；缺省为 `[start]`，`start` 会自动补入 |
| `variables` | 否 | 新游戏初始变量；只支持数字、布尔、字符串 |

变量会随存档保存，跨场景全局生效。

## 场景文件

每个场景对应 `scripts/scenes/<场景名>.yaml`：

```yaml
name: prologue            # 可选，仅作注释；实际场景名来自文件名
imports:                  # 可选；顶层字段，不能写成指令
  - smile_route
  - book_route

commands:
  - label: prologue_start
  - bg:
      image: images/bg/library_afternoon.svg
      transition: fade
      duration: 900
  - text: "九月的风穿过图书馆的长窗。"
```

- `commands` 必须是数组，**每个数组项只能包含一条指令**（一个键）。
- `imports` 只是把被导入文件的指令块与 `label` 注册进当前场景的“标签闭包”，**不会**顺序插入执行。被导入文件里的语句只能通过 `jump` / `label` 进入。
- 每个场景的入口块是它自己的文件块，从第 0 条指令开始执行。
- `import` 不能写成指令；写在 `commands` 里只会得到警告。

### 跨场景跳转

目标写法：

| 写法 | 含义 |
| --- | --- |
| `label` | 当前场景标签闭包（含 import 文件）中的标签 |
| `scene#label` | 另一个已加载场景中的标签；该场景必须出现在 `game.yaml` 的 `scenes` 中，或被其他已加载场景 import |

跨场景跳转后，执行从目标场景中该 `label` 的位置继续；舞台、变量、BGM 等状态保持。

## 指令参考

所有时长单位为毫秒。

### `bg` 背景

```yaml
- bg: images/bg/library_afternoon.svg          # 默认 fade 600ms
- bg:
    image: images/bg/library_sunset.svg
    transition: fade                          # fade | none
    duration: 900
- bg: null                                     # 切回纯黑，立即
- bg: { hide: true }                           # 同上
```

### `sprite` 立绘

```yaml
- sprite:
    id: sylvie                                # 必填，多立绘用 id 区分
    image: images/sprite/sylvie_neutral.svg
    position: center                          # left | center | right | 0-100（横向百分比）
    opacity: 1                                # 0-1，省略时显示为 1
    transition: fade
    duration: 600
- sprite: { id: sylvie, hide: true }          # 淡出并移除该立绘
```

`image` 省略或为 `null` 时按隐藏处理。同一 `id` 再次出现会替换素材与位置，不会叠出两张。

### `cg` 全屏 CG

```yaml
- cg: images/cg/book_glow.svg                  # 淡入 600ms
- cg:
    image: images/cg/tea_steam.svg
    visible: true
    transition: fade
    duration: 800
- cg: hide                                    # 或 cg: none
```

CG 位于立绘层之上、对话框之下。

### `text` 对话

```yaml
- text: "旁白也可以直接写成字符串。"
- text:
    speaker: 希尔维                            # 也可写 name
    text: "……你也听见了吗？刚才那段旋律。"
    voice: audio/voice/sylvie_01.wav           # 开始打字时播放
```

- 字符串简写不支持 `speaker` 与 `voice`。
- `speaker` 省略时按旁白处理（对话框中不显示名牌）。
- 每条 `text` 会阻塞，等待玩家点击 / 空格 / 回车。
- `text` 支持 `{变量名}` 插值，例如 `"好感度：{affection}"`，显示时使用当前变量值；`{{` / `}}` 表示字面花括号。未定义变量会保留占位符并产生警告。
- 文本 id 用于已读 / Skip 标记。默认由“块名 + 说话人 / 文本 / 语音的内容哈希”生成，因此插入或删除其他台词不会让未改动文本的已读记录错位；同一段重复台词按出现次数自动区分。需要固定关键台词时可显式指定 `id`：
  ```yaml
  - text: { id: "key-line", speaker: 希尔维, text: "……你也听见了吗？" }
  ```
  显式 `id` 是全局 key，跨场景复用同一台词时请自行加前缀避免碰撞。升级前生成的旧版 `block#下标` 已读记录仍会兼容命中，但重新播放后逐步迁移到新 id。

### `bgm` 背景音乐

```yaml
- bgm: audio/bgm/afternoon.wav                 # 默认 fade 500ms、loop true
- bgm:
    track: audio/bgm/sunset.wav
    fade: 800
    loop: true
- bgm: stop                                   # 淡出停止；none / 空字符串等价
```

### `se` 音效

```yaml
- se: audio/se/page_turn.wav                   # 默认音量 1
- se: { sound: audio/se/tea_cup.wav, volume: 0.8 }
```

### `voice` 语音

一般建议直接写在 `text.voice`，与文字同步播放。若需要在非文本时机播放：

```yaml
- voice: audio/voice/narrator_01.wav
- voice: { sound: audio/voice/narrator_01.wav }
```

新语音会打断上一条语音。

### `label` 标签

```yaml
- label: book_start
```

`label` 是跳转目标，本身不阻塞。引擎会把最近经过的 `label` 记录为存档的章节备注（`chapter`）。

### `jump` 无条件跳转

```yaml
- jump: book_start
- jump: "common#common_start"                  # 目标含 # 时建议加引号
```

### `choice` 选项

```yaml
- choice:
    prompt: 我该怎样回应她？                    # 也可写 title；省略则不显示
    options:
      - text: 问她手中的那本书
        jump: "book_route#book_start"
      - text: 先递给她一杯热茶
        jump: "smile_route#smile_start"
        set:                                   # 选中后、跳转前执行
          - { var: route, op: "=", value: "tea" }
          - { var: affection, op: "+=", value: 1 }
      - text: 把那段旋律哼给她听
        jump: melody_ending
        if: knows_melody                       # condition 为真时才显示
```

- `text` 与 `jump`（或 `target`）必填。
- `if`（或 `condition`）为条件表达式，假值时选项隐藏；表达式出错会告警并隐藏。
- `set`（或 `actions`）可选，接受单条赋值映射或列表，规则与顶层 `set` 相同；选中后先执行动作，再跳转。后续 `if` 可以读到这些变量。
- 选择后直接跳到目标 `label`，`choice` 后面的指令不会执行。建议把 `choice` 放在块末尾，或选择目标都是显式 `label`。
- 若所有选项都被隐藏，引擎告警并跳过该 `choice`。
- 播放器选项支持键盘：出现时聚焦第一项，`↑` / `↓` 切换，`1`–`9` 直接选择，`Enter` 确认当前项。

### `set` 变量

```yaml
- set: { var: affection, op: "+=", value: 2 }
- set: { var: route, op: "=", value: "book" }
- set: { var: knows_melody, op: "=", value: true }
- set: { var: affection, op: "=", expr: "affection + curiosity * 2" }
- set: { var: greeting, op: "=", expr: "'你好，' + player_name" }
```

`op` 只能是 `=`、`+=`、`-=`。`value` 与 `expr` 二选一；`expr` 复用条件表达式解析器，可使用变量、算术、比较与字符串拼接。

- `+=` 在任一侧为字符串时做拼接（例如 `prefix += "！"`），否则按数字相加。
- `-=` 要求变量与右侧都是数字，否则告警并忽略。
- 表达式求值失败只影响本条 `set`，会进入警告面板，不会中断剧情。

### `if` 条件跳转

```yaml
- if:
    condition: route == "smile"
    then: smile_epilogue
    else: book_epilogue
```

- `then` 必填；`else` 可选。
- 条件为真跳到 `then`，为假跳到 `else`；没有 `else` 时继续执行下一条。
- `then` / `else` 支持 `scene#label`。

### `wait` 等待

```yaml
- wait: 500
- wait: { duration: 1200 }
```

暂停自动推进，玩家点击可立即结束等待。

## 条件表达式

`if`、选项 `if` 使用同一套表达式语法，不经过 `eval`。

- 值：数字、单/双引号字符串、`true` / `false`、变量名。
- 变量：直接写变量名，例如 `affection >= 3`；未定义变量视为假。
- 运算：`+ - * /`、比较 `== != < <= > >=`、逻辑 `&& || !`、括号。
- `+` 在任一侧为字符串时做拼接，其余算术运算符要求数字。
- 真值语义：`false`、`0`、空字符串为假，其余为真。

```yaml
if: affection >= 2 && route == "smile"
if: knows_melody
if: !(curiosity > 5) || player_name == "旅人"
```

表达式本身不支持 `{}` 插值、函数调用或三目运算。文本展示需要拼接时，优先在 `text` 中使用 `{变量名}` 插值，或用 `set.expr` 预先拼好字符串变量。

## 舞台与状态约定

- 图层顺序：背景 → 立绘（多张共存）→ CG → 对话 UI → 选项 → 菜单遮罩。
- 转场一期只支持 `fade` / `none`。
- `bg` / `sprite` / `cg` / `bgm` 的当前状态会写入存档；读档后不重新执行这些指令，而是直接恢复画面与 BGM。`se` / `voice` 是一次性效果，不进入存档。
- 进入场景时播放器会预加载该场景（含 import 闭包）引用的全部资源；缺失资源会在启动或切换场景时输出警告。

## 校验与排错

```bash
pnpm validate
```

会完成以下检查：

- YAML 语法、清单字段、场景文件是否存在；
- 指令结构、字段类型、`op` / `position` / 时长等取值；
- `label` 重复、`jump` / `if` / `choice` 目标是否存在（含跨场景）；
- 表达式语法；
- 场景引用资源是否存在；
- 以真实引擎从 `start` 开始自动推进，分别走通所有分支到结局。

桌面与 Web 运行时，警告同时输出到开发者工具控制台，并汇总到播放器内的「脚本警告」面板；启动失败时可复制诊断信息。`text` 中的占位符语法也会在加载阶段检查。

## 写作建议

1. 每个场景文件聚焦一段连续剧情，分支入口用 `label` 明确定义。
2. `choice` 放在块末尾，避免“选择后自然继续”的歧义。
3. 跨场景跳转统一写 `scene#label` 并加引号，便于搜索。
4. 公共尾声放在 `common.yaml`，用 `if` 收敛分支。
5. 调整无关台词不会影响已读记录；若要重排或改掉关键台词原文，记得给它显式 `id`，保持已读标记稳定。
