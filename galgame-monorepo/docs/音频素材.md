# 音频来源与用途

- BGM 由项目所有者提供，统一使用 `bgm/night.mp3` 与 `bgm/music_box.mp3` 两首；替换或分发前请自行确认授权。
- 音效来自 CC0 / 公共领域素材。
- 本 demo 不附带角色语音；`voice` 指令仍由引擎支持，需要时可自行接入。
- 替换时保持文件名不变即可，剧本引用不需要改。

## BGM

| 文件 | 用途 |
| --- | --- |
| `bgm/music_box.mp3` | 开始界面与所有结局界面；八音盒质感，负责首尾氛围 |
| `bgm/night.mp3` | 游戏过程全程循环；深夜街道、售货机、图书馆、音乐教室、天台等所有场景共用 |

> 剧情正文不切换 BGM，`night.mp3` 会持续循环；直到弹出结局框时才切换为 `music_box.mp3`。
