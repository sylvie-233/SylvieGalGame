# 音频来源与用途

- BGM 由项目所有者提供，统一使用 `bgm/night.mp3`、`bgm/afternoon.mp3`、`bgm/music_box.mp3` 三首；替换或分发前请自行确认授权。
- 音效来自 CC0 / 公共领域素材。
- 本 demo 不附带角色语音；`voice` 指令仍由引擎支持，需要时可自行接入。
- 替换时保持文件名不变即可，剧本引用不需要改。

## BGM

| 文件 | 用途 |
| --- | --- |
| `bgm/music_box.mp3` | 开始界面（标题页 BGM）、旧音乐教室、回声结局；八音盒质感 |
| `bgm/night.mp3` | 深夜街道、售货机、末班车站、雨夜与沿河结局；贯穿全篇的夜间主题 |
| `bgm/afternoon.mp3` | 图书馆白天、天台黄昏、日常段落；温暖、怀旧 |

> `night.mp3` 会在多个场景重复使用，这是有意的主题复用。
